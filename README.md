# Ersti-Orakel

Studentische Testversion für Erstsemester am Campus Treskowallee der HTW Berlin, vor allem BWL. Kein offizielles Angebot der HTW Berlin. Verbindlich sind immer die verlinkten offiziellen Seiten.

Mit Kalli, dein Campushelfer. Der Chat ist ein Frage-Antwort-Bot ohne KI und läuft komplett im Browser.

Dieses Repository enthält nur die öffentlichen Website-Dateien. Verantwortlich: Hannah Wosnitza.
